## 2. Visita del nostro sito web

Il nostro sito web è gestito su server situati in Svizzera.

Durante la visita del sito vengono trattati i dati di log del server tecnicamente necessari. Tra questi possono rientrare in particolare l'indirizzo IP, la data e l'ora dell'accesso, le pagine consultate, il referrer e informazioni sul browser e sul sistema operativo.

Il fornitore di hosting tratta questi dati per nostro conto.

## 3. Analisi web con Rybbit

Utilizziamo Rybbit per l'analisi statistica dell'utilizzo del nostro sito web. Gestiamo Rybbit su un server situato in Svizzera.

Rybbit non utilizza cookie di analisi o pubblicitari e non memorizza informazioni di questo tipo sul suo dispositivo.

Vengono rilevati in particolare le pagine visitate, la durata della visita, il referrer, il browser, il sistema operativo, il tipo di dispositivo, le dimensioni dello schermo, la lingua e una posizione approssimativa derivata dall'indirizzo IP.

L'indirizzo IP viene utilizzato per determinare la posizione approssimativa e non viene memorizzato in modo permanente. Per distinguere le visite viene generato un identificativo pseudonimo a partire da informazioni tecniche. I dati di analisi vengono utilizzati esclusivamente per scopi statistici interni.

Il nostro sito web non utilizza cookie pubblicitari o di tracciamento, plugin dei social media né caratteri caricati dall'esterno.
